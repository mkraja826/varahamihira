# Phase 4 Kundli compatibility interpretation v1

This module consumes `compatibility_facts_v2` from Astro and produces a source-traceable comparison report. It does not recalculate astronomical facts.

## Output

- eight component explanations with evaluated or abstained status
- achieved and maximum points retained from Astro
- component bands: supportive, mixed, challenging, or insufficient
- partnership outlook index using `outlook_index_v1`
- evidence references for every component and the partnership index
- up to three strengths and three cautions
- contextual Manglik comparison based on independent Lagna, Moon, and Venus facts
- explicit non-probability and non-guarantee disclaimer

## Coverage

A complete role-aware Astro fact set has 36 evaluated maximum points. A role-neutral fact set has 27 evaluated maximum points and three explicit abstentions. Partial coverage is reported and never converted into false zero scores.

## Safety boundaries

The interpretation must not:

- claim that a score predicts marriage success or failure
- treat Manglik placement as an automatic rejection rule
- infer missing bride/groom roles
- turn abstentions into zero points
- provide medical, fertility, lifespan, wealth, divorce, or event-timing certainty
- recommend fear-based remedies

The partnership index remains uncalibrated. It is an interpretive comparison aid, not an objective measurement or probability.
