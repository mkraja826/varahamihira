# Varahamihira Engine

### Deterministic, source-traceable classical interpretation engine

A Python package derived from reviewed rules in **Varāhamihira's _Bṛhat Jātaka_**, designed for integration with the Astro and Horos projects.

**Python 3.12 · Pytest · Ruff · Zero runtime dependencies**

</div>

---

## Overview

The Varahamihira Engine separates classical interpretation from astronomical calculation.

It does **not** calculate planetary positions, charts, Panchanga, or ephemerides. Those astronomical facts are supplied by the Astro/Jyothisyam service. This repository focuses on turning reviewed classical rules into deterministic, testable outputs with explicit source provenance.

The project is intentionally strict about attribution: no rule is described as coming from _Bṛhat Jātaka_ until its source reference has been reviewed against the pinned edition.

## Design Principles

```text
Astronomical Facts
      │
      ▼
Classical Rules
      │
      ▼
Deterministic Resolution
      │
      ▼
Structured Interpretation
      │
      ▼
Consumer Wording
```

Each layer has a separate responsibility.

- **Astronomical facts** come from the astronomy service.
- **Classical rules** must be tied to reviewed textual sources.
- **Conflict resolution** must be deterministic and reproducible.
- **Consumer wording** may change presentation, but cannot change the underlying result.

This boundary prevents UI wording, AI-generated prose, or downstream products from silently changing the rule engine itself.

## Source Traceability

The engine is built around a pinned public-domain edition of _Bṛhat Jātaka_. Classical facts are expected to retain identifiers that can be traced back to approved source material.

A rule cannot enter the classical layer merely because it is commonly repeated online or generated by an AI system. Unsupported or invented verses are not accepted as evidence.

## Deterministic Interpretation

The project is designed so identical structured inputs produce identical structured outputs.

This makes the engine suitable for:

- repeatable automated testing;
- regression analysis;
- API integration;
- rule-by-rule editorial review;
- transparent debugging;
- controlled evolution of classical interpretation logic.

## Relationship to Astro

```text
Astro / Jyothisyam
  Skyfield + JPL DE440s
          │
          │ structured astronomical facts
          ▼
Varahamihira Engine
  reviewed classical rules
          │
          │ deterministic interpretation
          ▼
Horos / Consumer Applications
```

The **Astro repository owns astronomical calculations, regression baselines, and external-validation evidence**.

This repository owns the classical rule layer. Textual source review here does not independently validate planetary positions or astronomical calculations.

## Validation Boundaries

The project deliberately separates several types of confidence:

### Textual Review

A reviewed classical rule means that its source reference has been checked against the pinned edition and accepted into the engine.

### Software Regression

Automated tests help ensure deterministic behavior and protect against accidental changes to rule evaluation.

### Astronomical Validation

Planetary positions, charts, Panchanga and related calculations are outside this repository and must be validated in Astro.

### External Verification

Neither this engine nor downstream applications should claim independent external-software verification unless the required evidence has been recorded and approved in the Astro validation system.

## Engineering Goal

The purpose of this repository is not to create an opaque "astrology AI." It is to model a bounded set of classical rules as software that can be inspected, sourced, tested, and versioned.

That means every expansion of the engine should preserve:

- provenance;
- deterministic behavior;
- explicit rule boundaries;
- test coverage;
- separation from astronomical computation;
- separation from presentation wording.

## Responsible Use

Astrology is not scientifically established as a reliable predictor of future events. Outputs derived from this engine are intended for cultural, spiritual, educational, and reflective use.

They should not be treated as medical, legal, mental-health, financial, or other professional advice.

## Project Status

**Active research and engineering development.**

The engine currently serves as the classical interpretation layer for the broader Astro/Jyothisyam and Horos architecture and is being expanded through reviewed, source-traceable rule implementation rather than unrestricted rule ingestion.
